## Actual sample data

The hotel sample was exported by an ordinary cup pickup and placement, not by
teleporting objects, forcing completion or supplying fake prerecorded images.
It contains **15 RGB/depth/instance frames**, Room and Robot views,
and **2 completed assisted actions**. It is a short partial
mission, not a recording of a complete six-shift campaign. Actions, symbolic grasp
relations and null unavailable forces/tactile were checked in the downloaded ZIP.
The separate full gameplay suite completes the campaign through ordinary controls.

The bench sample has **67 model steps**, generated by moving the
indentation slider up and down. All 16 × 16 pressure grids integrate to their
modeled normal force within 1e-5 N. Begin/persist/end phases were observed. This is
an independent analytic fixture, not a sensor mounted on the hotel robot.

The example frame decoded to 162,240 valid world points.
Maximum source-raster round-trip reprojection error was
4.55e-13 pixels. This is an algebra/coordinate
consistency check, not a physical calibration or reconstruction-accuracy result.
RGB, depth and false-color instance previews were visually inspected.

## Browser restrictions and GPU status

The environment's normal HTTP navigation returned
`net::ERR_BLOCKED_BY_ADMINISTRATOR`. Its WebGL2 context was null. The actual
navigation failure and WebGL availability probe are included in evidence.
Managed browser settings were not changed or bypassed.

Full gameplay tests use `--memory --renderer cpu`: the same modules as blob URLs
and the actual styles in an allowed blank page. Only that test document removes
the source CSP. Capture/model are mocked in the named hand-control tests. The
standalone/recording tests instead use the exact bundled document with its own CSP
retained, still through set_content rather than file:// or HTTP navigation.

Therefore **all screenshots and executed renderer tests use CPU/WASM**. The new
WebGL2 shader backend, GPU sensor framebuffer readback, hardware context loss and
its performance are **not validated**. Syntax checks do not compile GLSL. The
opt-in deployment workflow requires a GPU HTTP pass rather than silently accepting
fallback; that workflow has not run. Normal source CSP, real MediaPipe downloads,
webcam permission/accuracy, Safari/Firefox and device memory/latency remain gates.

No synthetic camera test establishes physical hand control quality. No real user
webcam frames or microphone recordings appear in the evidence or example archives.
No real API key was supplied or used. Provider tests remain mocked.

## Scientific and visual limits

The hotel is authored geometry with approximate materials and lighting, not a
scanned, calibrated or photorealistic room. CPU camera rendering can remain slow;
no measured device FPS, thermal, GPU speed-up or input-latency claim is made.
The bench is a new navigation obstacle, not a dynamic rigid body. Cloth and liquids
are not simulated. Hotel grasp/placement and arm motion remain assisted kinematics.

Hotel support/grasp relations are symbolic and labeled as such. Contact points,
normals, impulses, forces, joint states/torques and tactile measurements that are
not present are null/unavailable. The pressure bench models only prescribed normal
indentation; it has no object/contact solver, shear/slip or sensor calibration.
This release tests collection/provenance, not robot-learning utility, sim-to-real
transfer, hospitality procedures, accessibility certification or production security.

## Defects caught / changes checked

The original screen-space AO compared raw depth across a sloping plane and produced
false large diagonal shadows. The fix compensates reciprocal-depth slope; an isolated
plane regression checks it does not gain spurious shading. Instance labels survive
static buffer caching and depth occlusion. Visual-only shadow polygons do not overwrite
sensor depth/labels. Robot and held-object visual poses rotate with the base. Held
visual origins differ from task anchors and are exported separately. Source-raster
intrinsics and nearest-neighbor sampling are recorded rather than silently treating
resampled pixel centers as exact original rays. Pressure maps preserve force and
compute CoP from actual discrete cells; malformed/underflowing grids are rejected.
